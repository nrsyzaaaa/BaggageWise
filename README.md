# BaggageWise

**Calculate Smart. Travel Easy.**

## About the Application
BaggageWise is a mobile application developed to help travellers calculate excess baggage fees based on their baggage weight, ticket class and excess baggage rate.

## Main Features
- Calculate excess baggage weight.
- Support Economy and Business ticket classes.
- Calculate excess baggage charges.
- Automatically calculate 8% service tax.
- Display the total payable amount.
- Reset input fields.
- Share application link.
- View application information through the About page.

## Calculation
- Economy Class: 20 kg baggage allowance.
- Business Class: 40 kg baggage allowance.
- Excess Baggage = Actual Weight − Baggage Allowance.
- Excess Charge = Excess Weight × Rate per kg.
- Service Tax = Excess Charge × 8%.
- Total Payable = Excess Charge + Service Tax.

## Technologies Used
- Android Studio
- Java
- XML
- Android SDK (API 30)

## How to Use
1. Enter the baggage weight in kilograms.
2. Select the ticket class.
3. Enter the excess baggage rate per kilogram.
4. Tap **Calculate Fee** to view the result.
5. Tap **Reset** to clear the inputs.
